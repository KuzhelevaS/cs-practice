Рабочая папка - это директория проекта, в которой хранятся все файлы.

Индекс - это состояние изменённых файлов. Это подготовленные к коммиту файлы.

Коммит - это сохраненное в историю состояние репозитория. Содержит изменения относительно прошлого коммита.

Git и Github отличаются тем, что git - это инструмент контроля версий для распределённой работы, а github - хостинг, удалённый сервер с файлами, позволяющий получить доступ к репозиторию через интернет

## Использованные команды

* git status - показывает изменения состояния файлов - нет изменений, файлы изменены, но не добавлены в индекс, файлы готовы к сохранению в историю.
* git diff - показывает различия в содержимом файлов. Сравнивает рабочую директорию и прошлый коммит
* git diff --staged (синоним git diff --cached) - полезен, когда мы добавили файлы в индекс. Сравнивает содержимое файлов в индексе и последнем коммите
