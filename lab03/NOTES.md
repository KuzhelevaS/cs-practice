git diff отличается от git show тем, что show показывает изменения в конкретном коммите, а diff позволяет сравнить не только 2 коммита, но и состояния репозиториев (индекс, рабочая область, произвольные коммиты)

git log показывает список коммитов и информацию о них

log -S в лабораторной ничего не нашёл, т.к. у меня не было использовано слово "def", но в целом команда производит поиск коммитов, содержащих поисковой запрос в истории коммитов

blame - показывает, в каком коммите были последние изменения для каждой строки документа
